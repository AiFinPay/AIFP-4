# AIFP-4 Roadmap

## Phase 0 — Public standard foundation

- Protocol positioning and global partner model.
- Core specification and message taxonomy.
- Architecture, security, compliance boundaries, economics, and state machine.
- OpenAPI 3.1 and initial JSON Schemas.
- Governance, contribution, security disclosure, and licensing.

## Phase 1 — Sandbox control plane

- Organization Registry.
- Legal entities, departments, cost centers, projects, and beneficiaries.
- AIFP-3 authority verification.
- Payment Intent API.
- Policy-as-code engine.
- Approval workflows.
- Signed event envelope and Treasury Receipt.
- TypeScript reference SDK and CLI.
- Sandbox execution adapter.

## Phase 2 — First production corridor

- One contracted licensed partner.
- One business-customer corridor.
- Fiat or stablecoin settlement rail.
- Partner capability manifest.
- Signed webhooks.
- Reconciliation and exception handling.
- Security assessment and operational readiness.
- Limited production pilot.

## Phase 3 — Multi-partner routing

- Multiple partners and route quotes.
- Jurisdiction packs.
- Health, capacity, cost, FX, and reliability scoring.
- Partner circuit breakers.
- Returns, cancellation, and compliance-hold workflows.
- ERP/accounting connectors.

## Phase 4 — Global network expansion

- Regional partner clusters.
- Cross-border supplier and intercompany settlement.
- ISO 20022 mapping profiles.
- Travel Rule interoperability where required.
- White-label and dedicated enterprise deployments.
- Partner certification and conformance program.

## Phase 5 — Autonomous treasury network

- Predictive liquidity and budget allocation under explicit policy.
- Netting and scheduled treasury sweeps.
- Multi-currency optimization.
- Agent-to-agent organizational settlement.
- Continuous risk, audit, and reconciliation.

## Production gate

A feature is production-ready only after specification, implementation, tests, threat review, security controls, partner/legal approval where applicable, monitoring, incident response, reconciliation, and rollback procedures are complete.
