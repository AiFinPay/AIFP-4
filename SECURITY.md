# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for suspected vulnerabilities. Report privately through the security contact published on the official AiFinPay website or GitHub organization security page.

Include affected component, reproducible steps, expected impact, relevant logs with secrets removed, and a safe proof of concept.

## Scope

Security reports may cover protocol specifications, schemas, reference implementations, SDKs, signature handling, authorization, policy enforcement, approval workflows, partner callbacks, receipt verification, tenant isolation, and reconciliation.

## Public disclosure

Coordinated disclosure is required. Do not publish exploit details before a fix or mitigation is available and affected partners have had a reasonable remediation window.

## Repository hygiene

Never commit secrets, private keys, seed phrases, production credentials, real customer or partner data, regulated personal data, internal production endpoints, or operational bypass procedures.
